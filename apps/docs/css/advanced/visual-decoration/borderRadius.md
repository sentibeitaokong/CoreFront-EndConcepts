# CSS 圆角 (`border-radius`)

从最基础的“**让按钮变圆**”，到高级的“**异形设计**”，`border-radius` 是 CSS 中使用频率最高的属性之一。它看似简单，但背后的百分比计算、椭圆半径、重叠缩放等细节，恰恰是很多“**圆角怎么不对劲**”问题的根源。

## 1. 基础语法

`border-radius` 是一个简写属性，用于设置元素外边框的圆角。它同时作用于四个角。

```css
/* 设置所有 4 个角为 10px */
.box {
  border-radius: 10px;
}
```

| 单位         | 说明                   | 相对谁                                                  |
| ------------ | ---------------------- | ------------------------------------------------------- |
| `px`         | 固定圆角大小（最常用） | 无                                                      |
| `%`          | 百分比圆角             | **元素自身的宽 / 高**（水平半径相对宽，垂直半径相对高） |
| `em` / `rem` | 跟随字号缩放           | 当前元素的字体大小                                      |

**理解百分比的关键**：每个角其实由「**水平半径 + 垂直半径**」组成（一个椭圆的两个半轴）。百分比时，水平半径相对元素的 **width**，垂直半径相对元素的 **height**。

- `border-radius: 50%` 在**正方形**上 → 水平半径 = 50% 宽，垂直半径 = 50% 高，两者相等 → **正圆**。
- `border-radius: 50%` 在**长方形**上 → 水平半径 = 50% 宽，垂直半径 = 50% 高，两者不等 → **椭圆**。

> 所以“`50%` 变圆”这个说法只在正方形上成立，长方形上它变的是椭圆。

## 2. 控制单个角 (顺时针规则)

你可以分别为 4 个角设置不同的值，顺序遵循 **“左上 -> 右上 -> 右下 -> 左下”** (顺时针)。

| 值个数     | 语法示例                              | 解释                                                   |
| :--------- | :------------------------------------ | :----------------------------------------------------- |
| **1 个值** | `border-radius: 10px;`                | 4 个角全是 10px。                                      |
| **2 个值** | `border-radius: 10px 50px;`           | **对角相等**。<br>左上+右下 = 10px；右上+左下 = 50px。 |
| **3 个值** | `border-radius: 10px 50px 20px;`      | 左上 = 10px；右上+左下 = 50px；右下 = 20px。           |
| **4 个值** | `border-radius: 10px 20px 30px 40px;` | 左上、右上、右下、左下。                               |

**单个角也能写两个值**（水平半径 + 垂直半径），中间用空格分隔：

```css
/* 左上角：水平半径 50px，垂直半径 25px → 一个“躺着的”椭圆角 */
.weird-corner {
  border-top-left-radius: 50px 25px;
}
```

`border-radius` 最完整的形式可以写 **8 个值**，用 `/` 把「水平半径组」和「垂直半径组」分开：

```markdown
border-radius: 水平1 水平2 水平3 水平4 / 垂直1 垂直2 垂直3 垂直4;
```

## 3. 常见形状“**配方**”

### 3.1 正圆

要求：宽度和高度必须相等。

```css
.circle {
  width: 100px;
  height: 100px;
  border-radius: 50%;
}
```

![Logo](/img/circle.png)

### 3.2 胶囊/药丸按钮

无论按钮多宽，两头始终保持半圆。
**技巧**：设置一个**极大的像素值**，让浏览器自动把它“**压缩**”成正好一半（见 [5 重叠缩放](#5-关键机制重叠圆角的自动缩放)）。

```css
.btn {
  height: 40px;
  /* 不要用 50%，否则长方形按钮会变成难看的椭圆 */
  border-radius: 9999px;
}
```

![Logo](/img/pillShape.png)

### 3.3 聊天气泡 / 树叶形

只设置对角，或者 3 个角。

```css
.message-bubble {
  border-radius: 15px 15px 0 15px; /* 左下角是直角 */
}
```

![Logo](/img/bubble.png)

```css
.leaf {
  border-radius: 0 50% 0 50%; /* 像一片叶子 */
}
```

![Logo](/img/leaf.png)

### 3.4 半圆 / 四分之一圆

只需把对应角的半径设为等于（或大于）那条边的长度即可。

```css
/* 上半圆：高度是宽度的一半，顶部两个角半径 = 高度 */
.semi-circle {
  width: 100px;
  height: 50px;
  border-radius: 50px 50px 0 0;
}

/* 四分之一圆：左上角半径 = 边长，其余直角 */
.quarter {
  width: 100px;
  height: 100px;
  border-radius: 100px 0 0 0;
}
```

> `border-radius` 只能产生**向外凸**的圆角。像“**向内凹的缺口**”（notch）这类形状它画不出来，需要借助 `clip-path` 或伪元素实现。

## 4. 椭圆圆角 (斜杠语法)

标准的 `border-radius: 50px` 画出的是正圆的一角。如果你想画**椭圆**的一角，需要使用 `/` 分隔水平半径和垂直半径。

**语法**：`border-radius: 水平半径 / 垂直半径;`

```css
/* 水平方向半径 100px，垂直方向半径 50px */
.ellipse-corner {
  border-radius: 100px / 50px;
}
```

![Logo](/img/corner.png)

`/` 前后的值同样遵循顺时针规则，可以各写 1~4 个：

```css
/* 四个角水平半径不同，垂直半径统一为 30px */
.egg {
  border-radius: 50% 30% 50% 30% / 30px;
}
```

```css
/* 这种写法能创造出类似“手绘不规则圆”的效果 */
.blob {
  border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%;
}
```

![Logo](/img/blob.png)

## 5. 重叠圆角的自动缩放

当**相邻两个角的半径之和超过该边长度**时，浏览器会按比例**等比缩小**所有圆角，直到刚好放得下。

例如 `100px × 40px` 的按钮写 `border-radius: 9999px`：水平两个半径之和远超宽度 `100px`，被缩到 `50px`（一半宽）；垂直同理被缩到 `20px`（一半高）。最终每个角变成「水平 50px、垂直 20px」的椭圆——恰好是胶囊的圆头。

**实用结论**：画胶囊写个足够大的值（`9999px`）最省心，浏览器会帮你“**截断**”；但若精确指定各角半径且超了边长，浏览器会**偷偷按比例缩小**，导致“**我写了 100px 怎么没生效**”——这是规范行为，不是 bug。

## 6. 常见问题 (FAQ)

### 6.1 里面的图片溢出了圆角怎么办？

**现象**：给 div 设了圆角，但里面的 `<img>` 还是直角的，把圆角盖住了。

**原因**：`border-radius` 只裁剪元素的**背景和边框**，**不会裁剪子元素**。

**解法**：在父容器上加 `overflow: hidden`。

```css
.card {
  border-radius: 10px;
  overflow: hidden; /* 关键属性：切掉溢出的子元素 */
}
```

### 6.2 边框 (Border) 和 圆角 的关系？

如果元素有边框，`border-radius` 设置的是**边框外侧**的圆角。

- **内侧圆角**会自动计算：`内侧半径 = 外侧半径 - 边框厚度`。
- 如果 `边框厚度 > 外侧半径`，内侧就会变成直角。

![Logo](/img/borderCompareRadius.png)

### 6.3 嵌套圆角如何看起来才“协调”？

如果你有一个外框（圆角 20px）和一个内部按钮，内部按钮的圆角应该是多少才好看？
**公式**：`内圆角 = 外圆角 - Padding`

```css
.outer {
  padding: 10px;
  border-radius: 20px;
}
.inner {
  /* 视觉上最完美的同心圆角 */
  border-radius: 10px; /* 20px - 10px */
}
```

![Logo](/img/outerAndInnerCircle.png)

### 6.4 为什么 `outline` 不跟着圆角走？

`outline`（轮廓）与 `border` 不同，它**不跟随 `border-radius`**，永远是直角（各主流浏览器的现状）。所以当你同时用 `outline` 做焦点高亮、又给元素设了大圆角时，会看到一圈直角方框——这是预期行为，不是 bug。需要圆角高亮时，改用 `border` 或 `box-shadow` 代替。

### 6.5 给 `<table>` 设圆角为什么不生效？

当表格使用 `border-collapse: collapse`（边框合并）时，`border-radius` 对表格整体**不生效**。因为合并边框模型下，表格的边框由各单元格的边框拼接而成，没有统一的“**外边框**”可以圆角。解决方式：改用 `border-collapse: separate`，或用外层容器包裹表格来做圆角 + `overflow: hidden`。

### 6.6 圆角会随元素尺寸自适应吗？

**`%` 会，`px` 不会。** 这是百分比圆角的核心价值：

```css
/* 自适应头像：无论容器多大，始终是正圆/椭圆 */
.avatar {
  width: 20%; /* 尺寸会变 */
  border-radius: 50%; /* 永远保持圆/椭圆 */
}
```

而固定 `px` 圆角在元素尺寸变化时会显得不协调。需要“**圆角随尺寸等比缩放**”的场景，优先用 `%`。
