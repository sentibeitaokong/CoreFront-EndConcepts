# 多列布局 (CSS Multi-column Layout)

CSS Multi-column 模块的核心逻辑是：把一个容器内的内容（文本、图片等）**自动拆分成多列**，像报纸、杂志排版一样，让长文本更易阅读、让卡片列表更紧凑。

**一句话理解**：**「Multi-column 是 CSS 里的『分栏』工具——你只需声明『要几列 / 每列多宽』，浏览器自动帮你灌内容、算列宽，并处理好跨列与断裂。」**

## 1. 容器属性 API (Container Properties)

这些属性必须设置在**父容器**上。

### 1.1 定义列的核心属性

[width(16,26,58)]

| 属性               | 语法 / 示例                                   | 详细逻辑                                                                                                                      |
| :----------------- | :-------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| **`column-count`** | `<integer> \| auto`<br>`column-count: 3;`     | **列数上限**。<br>强制指定「最多」分几列，浏览器据此自动反推每列宽度。<br>不写宽度时，列宽会随容器伸缩。                      |
| **`column-width`** | `<length> \| auto`<br>`column-width: 200px;`  | **列宽下限**（理想列宽）。<br>浏览器计算「容器能塞下几列」：<br>容器 500px 设 200px → 放 2 列（每列约 242px），剩余空间均分。 |
| **`columns`**      | `[width] \|\| [count]`<br>`columns: 3 200px;` | **简写属性**（顺序可互换）。<br>表示：**「最多 3 列，且每列不能小于 200px」**。<br>这是最省心的响应式写法。                   |

![Logo](/img/multiColumnFirst.png)

```css
/* 容器 800px，列间距默认 1em（约 16px） */
.columns {
  column-width: 300px; /* 理想列宽 300px */
  column-count: 4; /* 但最多只给 4 列 */
}
/* 800px 下能放 2 列（每列约 390px）；即便把容器加宽到 2000px，也最多 4 列 */
```

> 规则速记：**`column-count` 决定「最多几列」，`column-width` 决定「每列至少多宽」，浏览器取二者交集。**

### 1.2 样式与间距

[width(19,26,55)]

| 属性              | 语法 / 示例                                           | 详细逻辑                                                                                                 |
| :---------------- | :---------------------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| **`column-gap`**  | `<length> \| normal`<br>`column-gap: 20px;`           | **列间距**。<br>默认值 `normal` 通常等于 `1em`。<br>支持 `px`, `%`, `em` 等。                            |
| **`column-rule`** | `width style color`<br>`column-rule: 1px solid #ccc;` | **列分割线**。<br>语法完全等同于 `border`。<br>**注意**：分割线绘制在 Gap 中间，**不占据任何布局空间**。 |

![Logo](/img/multiColumnSecond.png)

`column-rule` 是下面三个长属性的简写，可单独设置：

```css
.multi {
  column-rule-width: 1px;
  column-rule-style: dashed;
  column-rule-color: #ccc;
}
```

> 小知识：`column-gap` 现在是**跨布局通用**的间距属性——Flexbox 和 Grid 也用它（老写法 `grid-column-gap` 等已废弃），统一记 `column-gap` / `row-gap` 即可。

### 1.3 填充模式 (高级)

[width(20,21,59)]

| 属性              | 值                   | 描述                                                                     |
| :---------------- | :------------------- | :----------------------------------------------------------------------- |
| **`column-fill`** | **`balance`** (默认) | **平衡填充**。<br>浏览器尽力让所有列高度一致，适合文章阅读。             |
|                   | `auto`               | **顺序填充**。<br>先填满第一列，再填第二列，逐列往下。**适合做瀑布流**。 |

> `column-fill` **只在容器有确定高度（如 `height: 400px`）时才生效**；高度由内容撑开的容器里，这个属性基本无感。

## 2. 子元素属性 API (Item Properties)

这些属性设置在多列容器内部的**子元素**（如 `h2`, `p`, `.card`）上。

### 2.1 跨列 (Spanning)

[width(19,17,64)]

| 属性              | 值            | 描述                                                                                                       |
| :---------------- | :------------ | :--------------------------------------------------------------------------------------------------------- |
| **`column-span`** | `none` (默认) | 元素仅在自己的列宽内显示。                                                                                 |
|                   | **`all`**     | **横跨所有列**。<br>通常用于标题。元素会截断内容流：它之前的内容在上方平衡分列，之后的内容在下方重新分列。 |

![Logo](/img/multiColumnThird.png)

> `column-span: all` 的元素必须是**块级元素**，且必须直接参与多列内容流——把它放进 `display: flex` 之类的容器里，`column-span` 可能会失效。

### 2.2 断裂控制 (Fragmentation)

控制元素如何在列之间分割（防止图片/卡片被切成两半）。

[width(25,21,54)]

| 属性               | 值            | 描述                                                       |
| :----------------- | :------------ | :--------------------------------------------------------- |
| **`break-inside`** | `auto` (默认) | 允许在元素内部断开。                                       |
|                    | **`avoid`**   | **禁止断开**。<br>保持元素完整性。做瀑布流卡片时**必加**。 |
| `break-before`     | `column`      | 强制该元素位于**新的一列**的顶端。                         |
| `break-after`      | `column`      | 强制该元素之后**开启新的一列**。                           |

```css
/* 小标题强制另起一列，避免「标题孤零零待在上一栏底部」 */
h3 {
  break-before: column;
}
/* 整块引用不许被切开 */
blockquote {
  break-inside: avoid;
}
```

> **兼容性提示**：为了兼容旧版浏览器（如老 Webkit），建议同时加上 `-webkit-column-break-inside: avoid;` 和 `page-break-inside: avoid;`。

### 2.3 孤儿与寡行 (`orphans` / `widows`)

控制分栏时**栏底 / 栏顶**至少保留几行，避免出现「栏底只剩一行孤零零」的尴尬排版。

[width(24,19,57)]

| 属性          | 默认值 | 含义                             |
| :------------ | :----- | :------------------------------- |
| **`orphans`** | `2`    | 栏（或页）**底部**至少保留的行数 |
| **`widows`**  | `2`    | 栏（或页）**顶部**至少保留的行数 |

```css
p {
  orphans: 3; /* 栏底不足 3 行时，整段移到下一栏 */
  widows: 3; /* 栏顶不足 3 行时，从上一栏多拽一行过来 */
}
```

## 3. 实战案例

### 3.1 瀑布流卡片（最常见实战）

Multi-column 最出名的用法就是「瀑布流」（Pinterest 式卡片墙）：卡片按**纵向**依次灌入各列，天然形成错落感，而且**无需 JS**。

```css
.masonry {
  columns: 4 220px; /* 最多 4 列，每列至少 220px */
  column-gap: 16px;
}
.masonry .card {
  break-inside: avoid; /* 关键：卡片不跨列被切断 */
  -webkit-column-break-inside: avoid; /* Chrome/Safari 旧版 */
  page-break-inside: avoid; /* Firefox 旧版 */
  margin-bottom: 16px;
  display: inline-block; /* 修复个别浏览器的渲染 bug */
  width: 100%;
}
```

```html
<div class="masonry">
  <div class="card">...</div>
  <div class="card">...</div>
  <div class="card">...</div>
  <!-- ... -->
</div>
```

> 瀑布流的顺序是先第一列从上到下，再第二列」（纵向优先），不是「从左到右一行行」。若你需要**横向优先**的瀑布流，那得用 Grid（如 `grid-auto-flow: dense`），多列做不到。

### 3.2 响应式多列（无需媒体查询）

只用 `column-width`（不写 `column-count`），列数就会随容器宽度**自动增减**——这是多列布局最优雅的响应式写法：

```css
.text {
  column-width: 320px; /* 每列至少 320px，列数交给浏览器算 */
  column-gap: 32px;
}
/* 手机(≤320px) → 1 列；平板(700px) → 2 列；桌面(1400px) → 4 列 */
```

## 4. 选型：多列 vs Flex vs Grid

[width(30,22,48)]

| 需求                      | 推荐方案         | 原因                                       |
| :------------------------ | :--------------- | :----------------------------------------- |
| 报纸式长文排版            | **Multi-column** | 自动分栏、断裂/孤儿寡行控制都是原生能力    |
| 瀑布流（纵向优先）        | **Multi-column** | `break-inside: avoid` 天然支持，代码最少   |
| 单轴对齐 / 换行           | **Flexbox**      | `justify-content` / `align-items` 控制力强 |
| 二维精确网格 / 横向瀑布流 | **Grid**         | 行列精确控制，`grid-auto-flow` 等          |
| 表格型数据                | `display: table` | 语义化 + 天然对齐                          |

## 5. 常见问题 (FAQ) 与 故障排除

### 5.1 瀑布流的卡片被“腰斩”（切成两半）怎么办？

**现象**：一张卡片的上半部分在第一列底部，下半部分在第二列顶部。

**原因**：浏览器默认允许内容为了填满列而在任意位置断开。

```css
.card {
  break-inside: avoid; /* 标准 */
  -webkit-column-break-inside: avoid; /* Chrome/Safari 旧版 */
  page-break-inside: avoid; /* Firefox 旧版 */

  /* 有时候加上这个能解决极个别渲染 bug */
  display: inline-block;
  width: 100%;
}
```

### 5.2 瀑布流顶部有莫名其妙的空白？

**现象**：第一列或某一列的第一个元素，并没有顶格对齐，而是往下掉了一点。

**原因**：**Margin Collapse (外边距合并)**。子元素的 `margin-top` 穿透了父容器，或分列计算导致对齐异常。

**解决方案**：给父容器触发 BFC。

```css
.container {
  overflow: hidden;
}
```

### 5.3 `column-span: all` 导致下面的内容错乱？

**限制**：`column-span: all` 的元素必须是**块级元素**，且它是文档流的一部分。
如果在该元素之前的列填充高度计算出现小数点误差，可能会导致视觉上的错位。

**注意**：`column-span` 不能被包含在另一个块级上下文中（例如，如果父容器是 `display: flex`，里面的子元素再用 `column-span` 可能会失效）。

### 5.4 为什么设置了 `column-count: 3` 但只显示了 1 列？

**原因**：容器宽度太窄了。
如果你同时设置了 `column-width` 和 `column-count`（或用了 `columns` 简写），`column-width` 其实是一个「下限」：

**逻辑**：如果 `容器宽度 / 3` 小于 `column-width` 设定的最小值，浏览器就会减少列数，以保证每列宽度足够。

### 5.5 图片在多列里溢出了列宽怎么办？

**现象**：图片比列宽还宽，直接撑破列、甚至出现横向滚动。

**解法**：让图片跟随列宽自适应：

```css
.column img {
  max-width: 100%; /* 不超出列宽 */
  display: block; /* 消除图片基线下方的小空隙 */
}
```

### 5.6 怎么给每一列添加背景色？

**做不到**。
CSS Multi-column 无法直接给「列」这个概念添加背景。内容是流动的，并没有物理上的「第一列 DOM 元素」。

**替代方案**：只能给**子元素**添加背景，或者给父容器加一个条纹背景图 (`linear-gradient`) 来模拟列背景。

### 5.7 阴影 (`box-shadow`) 被切断了？

**现象**：卡片右侧有阴影，但在列的边缘被切掉了。

**原因**：多列容器默认会裁剪溢出到列外的内容。

**解决方案**：给卡片留出 `margin`，不要让阴影紧贴列的边缘；或者给容器加 `padding`。
