# CSS 选择器

CSS 选择器回答的是「**找到谁**」的问题：它决定了某条样式规则会应用到哪些 HTML 元素上。

## 1. 常见 CSS 选择器

我们可以把选择器分为几个梯队，从简单到强大逐一拆解。

### 1.1 基础选择器

最底层的四种选择器，是所有复合选择器的"**积木**"。

- **标签选择器 (Element Selector):** 直接选中标签名，命中范围最广。

```css
/* 选中所有 <p> */
p {
  color: red;
}
```

- **类选择器 (Class Selector):** 最常用的选择器，以 `.` 开头。一个元素可以有多个 class，因此类选择器天然适合复用。

```css
/* 选中所有 class="highlight" 的元素 */
.highlight {
  background: yellow;
}
```

- **ID 选择器:** 具有唯一性，以 `#` 开头。一个 ID 在文档中应当只出现一次。

```css
/* 选中 id="navbar" 的元素 */
#navbar {
  height: 50px;
}
```

- **通配符选择器:** 选中所有元素，常用于"**全局重置**"。

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

[width(22,17,61)]

| 选择器       | 示例     | 描述                                         |
| ------------ | -------- | -------------------------------------------- |
| 通配符选择器 | `*`      | 选中页面上所有元素。                         |
| 标签选择器   | `div`    | 选中指定标签名的所有元素（如所有 `<div>`）。 |
| 类选择器     | `.class` | 选中 class 属性包含指定值的所有元素。        |
| ID 选择器    | `#id`    | 选中 id 属性为指定值的唯一元素。             |

### 1.2 组合选择器

通过"**关系**"把多个选择器串起来，描述元素之间的结构关系。

- **后代选择器 (空格):** 选中某个元素内部的所有特定后代（包括子、孙子……）。

```css
/* 选中 .card 内部的所有 p（不限层级） */
.card p {
  margin: 0;
}
```

- **子选择器 (>):** 只选中直接子元素（"**儿子**"，不含孙子）。

```css
/* 选中 .list 的直接 li 子元素 */
.list > li {
  list-style: none;
}
```

- **相邻兄弟选择器 (+):** 选中紧接在某元素之后的第一个兄弟元素。

```css
/* 选中紧跟在 h1 之后的第一个 p */
h1 + p {
  font-size: 14px;
}
```

- **通用兄弟选择器 (~):** 选中某元素之后的所有同级兄弟元素。

```css
/* 选中 h1 之后的所有同级 p */
h1 ~ p {
  color: gray;
}
```

- **并集选择器 (,):** 同时选中多个，给它们套用同一组样式（分组）。

```css
/* 同时选中 h1、h2、.title */
h1,
h2,
.title {
  font-family: sans-serif;
}
```

- **列组合器 (||):** 选中属于某个 `<col>` 列的元素，极冷门，仅表格场景用到。

```css
/* 选中属于 .price 这一列的所有单元格 */
col.price||td {
  background: #f0f0f0;
}
```

[width(25,22,53)]

| 选择器         | 示例          | 描述                                |
| -------------- | ------------- | ----------------------------------- |
| 后代选择器     | `div p`       | 选中 div 内部的所有 p（子、孙……）。 |
| 子选择器       | `div > p`     | 选中 div 的直接子元素 p（仅儿子）。 |
| 相邻兄弟选择器 | `div + p`     | 选中紧接在 div 之后的第一个 p。     |
| 通用兄弟选择器 | `div ~ p`     | 选中 div 之后的所有同级 p。         |
| 列组合器       | `col \|\| td` | 选中属于某 `<col>` 列的单元格。     |
| 并集选择器     | `div, p`      | 同时选中 div 和 p（分组）。         |

### 1.3 属性选择器

根据元素的属性（或属性值）来选中元素，无需额外加 class，尤其适合表单和链接。

```css
/* 选中带有 title 属性的所有元素 */
[title] {
  cursor: help;
}

/* 选中 type 为 text 的 input */
input[type='text'] {
  border: 1px solid #ccc;
}

/* 选中 href 以 https 开头的链接 */
a[href^='https'] {
  color: green;
}
```

[width(21,26,53)]

| 选择器           | 示例                | 描述                                            |
| ---------------- | ------------------- | ----------------------------------------------- |
| `[attr]`         | `[target]`          | 选中**带有该属性**的元素。                      |
| `[attr=value]`   | `[type="text"]`     | 选中属性值**完全等于指定值**的元素。            |
| `[attr~=value]`  | `[title~="flower"]` | 选中属性值**包含指定单词**（空格分隔）的元素。  |
| `[attr\|=value]` | `[lang\|="en"]`     | 选中属性值等于 `value` 或 `value-` 开头的元素。 |
| `[attr^=value]`  | `[href^="https"]`   | 选中属性值以指定字符串**开头**的元素。          |
| `[attr$=value]`  | `[src$=".png"]`     | 选中属性值以指定字符串**结尾**的元素。          |
| `[attr*=value]`  | `[class*="icon"]`   | 选中属性值**包含指定子字符串**的元素。          |

**大小写标志（现代特性）**：默认对大小写敏感，可加 `i` 忽略大小写、`s` 强制敏感。

```css
/* 忽略大小写：能匹配 type="TEXT"、type="Text" 等 */
input[type='text' i] {
  border-color: blue;
}

/* 强制敏感：即使 HTML 属性本不区分大小写，也要求完全一致 */
[data-id='AbC' s] {
  color: red;
}
```

### 1.4 伪类选择器 (Pseudo-classes)

伪类用于选择元素的**特定状态**（如悬停、第几个、是否被选中等）。它们以单冒号 `:` 开头。

#### 1.4.1 交互与状态伪类 (User Action & State)

[width(22,78)]

| 伪类             | 描述                                                                             |
| ---------------- | -------------------------------------------------------------------------------- |
| `:hover`         | 鼠标悬停时。                                                                     |
| `:active`        | 元素被激活时（通常指鼠标按下的瞬间）。                                           |
| `:focus`         | 元素获得焦点时（如点击输入框）。                                                 |
| `:focus-visible` | 仅当通过键盘导航获得焦点时显示轮廓（提升无障碍体验，避免鼠标点击也出现焦点框）。 |
| `:focus-within`  | 当元素自身或其内部任何子元素获得焦点时（常用于让整个表单高亮）。                 |
| `:visited`       | 链接已被访问过。                                                                 |
| `:link`          | 链接尚未被访问。                                                                 |
| `:target`        | URL 锚点指向当前元素时（如 URL 为 `#section1` 时选中 `id="section1"` 的元素）。  |

```css
/* 链接四态顺序口诀：LoVe HAte（link → visited → hover → active） */
a:link {
  color: blue;
}
a:visited {
  color: purple;
}
a:hover {
  color: red;
}
a:active {
  color: orange;
}
```

#### 1.4.2 结构性伪类 (Structural)

[width(29,71)]

| 伪类                   | 描述                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| `:root`                | 文档的根元素（通常是 `<html>`）。                                            |
| `:empty`               | 没有子元素（**包括文本节点**）的元素。                                       |
| `:first-child`         | 是父元素的第一个子元素。                                                     |
| `:last-child`          | 是父元素的最后一个子元素。                                                   |
| `:only-child`          | 是父元素中唯一的子元素。                                                     |
| `:nth-child(n)`        | 是父元素的第 n 个子元素（**不区分类型**）。支持 `odd`、`even`、`An+B` 公式。 |
| `:nth-last-child(n)`   | 倒数第 n 个子元素。                                                          |
| `:first-of-type`       | 同类型兄弟中的第一个元素。                                                   |
| `:last-of-type`        | 同类型兄弟中的最后一个元素。                                                 |
| `:only-of-type`        | 同类型兄弟中唯一的元素。                                                     |
| `:nth-of-type(n)`      | 同类型兄弟中的第 n 个元素。                                                  |
| `:nth-last-of-type(n)` | 倒数第 n 个同类型兄弟元素。                                                  |

**`:nth-child()` 公式速查**（`An + B` 中，`n` 从 0 开始递增）：

[width(39,61)]

| 写法               | 选中                             |
| ------------------ | -------------------------------- |
| `:nth-child(3)`    | 第 3 个                          |
| `:nth-child(odd)`  | 奇数位（1, 3, 5……），等价 `2n+1` |
| `:nth-child(even)` | 偶数位（2, 4, 6……），等价 `2n`   |
| `:nth-child(3n)`   | 每 3 个中的第 1 个（3, 6, 9……）  |
| `:nth-child(n+3)`  | 第 3 个及之后所有（3, 4, 5……）   |
| `:nth-child(-n+3)` | 前 3 个（1, 2, 3）               |

> **记忆**：`nth-child` 数**所有兄弟**的第几个；`nth-of-type` 只数**同类型**兄弟的第几个。

#### 1.4.3 表单相关伪类 (Form)

[width(40,60)]

| 伪类                          | 描述                                              |
| ----------------------------- | ------------------------------------------------- |
| `:checked`                    | 被选中的 radio 或 checkbox。                      |
| `:disabled`                   | 被禁用的表单元素。                                |
| `:enabled`                    | 启用的表单元素。                                  |
| `:required`                   | 带有 `required` 属性的 input。                    |
| `:optional`                   | 没有 `required` 属性的 input。                    |
| `:valid` / `:invalid`         | 内容验证通过 / 不通过的 input。                   |
| `:in-range` / `:out-of-range` | 值在 / 不在规定范围内的 input（如 `min`/`max`）。 |
| `:read-only`                  | 只读的 input。                                    |
| `:read-write`                 | 可读写的 input。                                  |
| `:placeholder-shown`          | 当 input 显示占位符（即内容为空）时。             |
| `:default`                    | 默认选中的表单元素（如默认按钮）。                |

```css
/* 自定义勾选框的选中态 */
input[type='checkbox']:checked + label {
  color: #07c;
}
```

#### 1.4.4 逻辑组合伪类 (Functional / Logical) —— 现代 CSS 重点

[width(22,78)]

| 伪类                    | 描述                                                                               |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `:not(selector)`        | 否定伪类。选中**不匹配**参数选择器的元素。                                         |
| `:is(selector, ...)`    | 匹配伪类。选中匹配参数列表中**任意一个**的元素（常用于把一长串选择器压缩成一行）。 |
| `:where(selector, ...)` | 与 `:is()` 匹配能力相同，但**权重恒为 0**，适合写"可被轻易覆盖"的默认样式。        |
| `:has(selector)`        | **父级选择器**！如果元素包含匹配参数的后代（或后续兄弟），则选中该元素本身。       |

```css
/* :not —— 给「非按钮」的链接换样式 */
a:not(.btn) {
  text-decoration: underline;
}

/* :is —— 把一长串选择器压缩成一行 */
:is(h1, h2, h3) {
  font-family: serif;
}

/* :where —— 零权重的默认主题，业务代码轻松覆盖 */
:where(.theme-light, .theme-dark) {
  background: #fff;
}

/* :has —— 选中「包含图片的卡片」「后面紧跟按钮的输入框」 */
.card:has(img) {
  padding: 0;
}
input:has(+ button) {
  border-radius: 8px 0 0 8px;
}
```

### 1.5 伪元素选择器

选中元素的一部分，或者凭空创建"虚拟元素"。通常用双冒号 `::`（旧写法单冒号 `:` 也兼容，但推荐 `::`）。

[width(36,64)]

| 伪元素                   | 描述                                                       |
| ------------------------ | ---------------------------------------------------------- |
| `::before`               | 在元素内容**之前**插入生成内容（**必须配合 `content`**）。 |
| `::after`                | 在元素内容**之后**插入生成内容（**必须配合 `content`**）。 |
| `::first-letter`         | 选中块级元素第一行的第一个字母（做首字下沉）。             |
| `::first-line`           | 选中块级元素的第一行（随视口宽度变化）。                   |
| `::selection`            | 选中用户鼠标框选（高亮）的文本部分。                       |
| `::placeholder`          | 选中 input 的占位符文本样式。                              |
| `::marker`               | 选中列表项 `<li>` 前面的项目符号（圆点 / 数字）。          |
| `::backdrop`             | 选中 `<dialog>` 弹出层背后的遮罩背景。                     |
| `::file-selector-button` | 选中 `<input type="file">` 的"**选择文件**"按钮。          |

```css
/* 1. 清除浮动（经典用法） */
.clearfix::after {
  content: '';
  display: block;
  clear: both;
}

/* 2. 添加装饰性图标 / 徽标 */
.new::after {
  content: 'NEW';
  margin-left: 4px;
  font-size: 10px;
  color: white;
  background: red;
  border-radius: 2px;
  padding: 1px 3px;
}

/* 3. 自定义列表符号 */
li::marker {
  color: #07c;
  content: '→ ';
}

/* 4. 自定义选中文本颜色 */
::selection {
  background: #07c;
  color: white;
}
```

> **伪类 vs 伪元素**：伪类 `:` 描述的是元素的**状态**（"**悬停的那个**"），伪元素 `::` 描述的是元素的**某个部分或虚拟元素**（"**内容前面的那块**"）。一句话：`:` 选状态，`::` 造元素。

## 2. 选择器是怎么匹配的

浏览器从**右往左**匹配选择器——先找到最右边的"**关键选择器**"（key selector），再向左逐级验证祖先关系。

```css
.header .nav .list .item a {
  color: red;
}
/* 浏览器：先找页面里所有 <a>，再逐个往上查它的祖辈是不是 .item → .list → .nav → .header */
```

**推论**：越靠右的选择器越"**窄**"，性能越好（比如 `#app .item` 优于 `.header .item`，因为 `#app` 能快速缩小候选范围）。这也是**不要层级嵌套太深**的原因之一。

## 3. 实战建议

- **尽量少用 ID 选择器写样式**：ID 权重太高、复用性差，以后想覆盖它很难（原因见 [层叠与特异性](/css/basic/cascadeAndSpecificity)）。推荐主要用 Class 类选择器。

- **不要层级嵌套太深**：`.header .nav .list .item a { ... }` 这种写法结构脆弱、性能稍差。建议用 BEM 命名法（如 `.nav__link`）保持扁平。

- **优先语义化 + 属性选择器**：能用属性选择器（`[data-state="open"]`）表达的，就别为了样式去堆一堆 class。

- **善用现代逻辑伪类**：用 `:is()` 精简冗长的选择器列表，用 `:has()` 表达"**父级**"需求（否则你只能加 class 或用 JS）。

## 4. 常见问题 (FAQ)

### 4.1 为什么我的选择器不生效？

- 选择器拼写 / 关系符写错了？
- 目标元素根本不在选择器描述的层级里？
- 属性名写错了（如 `font-color` 其实不存在）？
- 被更高权重的规则覆盖了（权重问题见 [层叠与特异性](/css/basic/cascadeAndSpecificity)）？

### 4.2 `:nth-child` 和 `:nth-of-type` 到底差在哪？

`:nth-child(n)` 在所有兄弟元素里数第 n 个（**混着数**）；`:nth-of-type(n)` 只在**同标签类型**里数第 n 个。想选"**第 2 个 p，但中间可能夹着别的标签**"时，用 `:nth-of-type` 更稳。

### 4.3 `:not()` 里能放多个选择器吗？

能。`:not(.a, .b)` 等价于"**既不是 `.a` 也不是 `.b`**"。

### 4.4 伪元素一定要双冒号吗？

规范推荐 `::before` / `::after` 用双冒号，但浏览器对旧写法单冒号 `:before` 仍兼容。新伪元素（如 `::marker`、`::backdrop`）**只支持双冒号**，统一用 `::` 最省心。

### 4.5 `*` 选择器影响性能吗？

单独用 `* { margin: 0 }` 几乎可以忽略性能损耗，现代浏览器优化得很好；真正拖慢的是**过深的后代选择器**导致的大范围回溯匹配。别迷信"**通配符很慢**"的旧说法。
