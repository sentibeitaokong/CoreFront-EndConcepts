# CSS 继承 (Inheritance)

CSS 继承回答的是「**这个元素的值从哪来**」的问题：当一个元素没有显式设置某个属性时，该属性的值会自动从父元素"**遗传**"下来。

## 1. 哪些属性会继承？

并不是所有 CSS 属性都会继承。CSS 规范为每个属性定义了一个**初始值（initial value）**，以及一个**继承性（inherited）标记**：

- `Inherited: yes` → 未显式设置时，值来自父元素（即 `inherit`）；
- `Inherited: no` → 未显式设置时，使用规范定义的初始值（即 `initial`）。

### 1.1 可继承属性 (Inherited Properties)

这类属性大多与**文本内容**和**排版**相关。设计逻辑是：给整个段落设了字体颜色，你通常也希望段落里的强调文本 `<em>`、链接 `<a>`、代码 `<code>` 都是这个颜色——否则每个内联子元素都要单独设置一遍，太繁琐。

### 1.2 不可继承属性 (Non-inherited Properties)

这类属性大多与**盒模型、布局、背景、视觉效果**相关。设计逻辑是：给父元素加了红色边框或半透明背景，你**肯定不希望**所有子元素也自动带上红色边框、也跟着变半透明。

| 分类   | 属性                                | 说明             | 为什么不继承                   |

| 盒模型 | `box-sizing`                        | 盒模型计算方式   | —                              |
| 背景   | `background`（及 `background-*`）   | 背景色/图/定位等 | 背景铺在当前元素，不穿透       |
| 定位   | `position`                          | 定位方式         | 定位关系是个体的               |

| 显示   | `vertical-align`                    | 垂直对齐         | 只对齐当前元素自身             |

### 1.3 怎么快速判断一个属性是否继承？

- **查 MDN**：每个属性的页面上都有「Inherited: yes / no」一行，这是最权威的判断依据。
- **看 DevTools**：选中元素，Computed 面板里继承来的值会标出「Inherited from `<父元素>`」。
- **记规律**：文字/字体/列表/表格类 → 大多继承；盒模型/布局/背景/视觉类 → 大多不继承。遇到拿不准的再查 MDN。

## 2. 如何控制继承？

CSS 提供了五个全局关键字，可以**强制改变任何属性**的继承行为。它们本质上是"**值**"，可以用在任何 CSS 属性上（不只是继承相关属性）。

### 2.1 `inherit` —— 强制继承

**作用**：让该属性值等于父元素的值，**即使该属性默认不继承**。

**场景**：想让子元素的边框颜色和父元素完全一致；或让 `<a>` 继承父元素颜色（见 3.1）。

```css
.parent {
  border: 1px solid red;
  color: #333;
}
.child {
  border: inherit; /* 子元素也会得到 1px solid red */
  color: inherit; /* 显式继承父元素颜色 */
}
```

### 2.2 `initial` —— 重置为规范默认值

**作用**：把属性重置为 CSS 规范定义的**初始默认值**，完全忽略继承（也忽略浏览器给该元素的默认样式）。

**场景**：父元素设置了红色字体，但你希望某个子元素恢复为规范默认的黑色字体。

```css
.parent {
  color: red;
}
.child {
  color: initial; /* 变回规范默认（黑色） */
}
```

> 注意 `initial` 与「浏览器默认」的区别：`initial` 是**规范**里的初始值（如 `display: inline`），而浏览器默认（User Agent 样式表）会额外给 `<h1>`、`<ul>` 等元素加样式。想回到**浏览器默认**，应改用 2.4 的 `revert`。

### 2.3 `unset` —— 恢复"自然状态"

**作用**：智能关键字，按属性的"**天性**"处理：

- 属性**可继承**（如 `color`）→ 等同 `inherit`；
- 属性**不可继承**（如 `border`）→ 等同 `initial`。

**场景**：清理样式时最安全的"**一键还原**"。

```css
.box {
  color: unset; /* color 可继承 → 等同 inherit */
  border: unset; /* border 不可继承 → 等同 initial（无边框） */
}
```

### 2.4 `revert` —— 回退到浏览器/用户样式

**作用**：把属性回滚到**上一层来源**（通常是浏览器默认样式表 User Agent Stylesheet）的值。它比 `initial` 温和——保留了浏览器默认样式（比如 `<h1>` 的默认加粗大字），而 `initial` 会把 `<h1>` 变成普通文本大小。

```css
/* 想让某个元素"回归浏览器默认"，用 revert 而不是 initial */
h1 {
  font-size: revert; /* 回到浏览器给 h1 的默认字号 */
}
```

### 2.5 `revert-layer` —— 回退到上一层「层叠层」

**作用**：回退到**上一层层叠层**（`@layer`）里为该属性设置的值。只在使用了 `@layer` 的场景下有意义。

```css
@layer base, theme;

@layer base {
  button {
    background: gray;
  }
}
@layer theme {
  button {
    background: revert-layer; /* 回退到 base 层的 gray */
  }
}
```

> `@layer` 属于「层叠」主题，详见 [层叠与特异性](/css/basic/cascadeAndSpecificity)。

### 2.6 关键字速查表

| 关键字         | 作用                                                 | 相对谁"**回退**"  |
| -------------- | ---------------------------------------------------- | ----------------- |
| `inherit`      | 强制继承父元素的值（即使该属性默认不继承）。         | 父元素            |
| `initial`      | 使用该属性的规范初始值（忽略一切继承与浏览器默认）。 | 规范默认值        |
| `unset`        | 可继承属性 → 继承，不可继承属性 → 初始值。           | 按属性天性        |
| `revert`       | 回退到上一层来源（通常是浏览器默认样式）。           | 浏览器/用户样式表 |
| `revert-layer` | 回退到上一层层叠层的值。                             | 上一层 `@layer`   |

> **额外技巧**：`all` 属性可以一次性给元素的所有属性套用这些关键字，例如 `all: unset;` 是组件库常用的"**样式隔离**"手段；`all: revert;` 则常用于把某个组件整体"**打回浏览器默认**"。

## 3. 常见误区与注意点

### 3.1 为什么给 `body` 设了 `color: red`，链接 `<a>` 还是蓝色？

**原因**：浏览器默认样式表给 `<a>` 显式设置了 `color: -webkit-link`（蓝色）。因为**直接命中元素的声明永远赢过继承来的值**（详见 [层叠与特异性](/css/basic/cascadeAndSpecificity)），所以继承下来的红色被覆盖了。

**解决**：

```css
a {
  color: inherit; /* 显式让链接继承父元素颜色 */
}
```

### 3.2 `height: 100%` 是继承吗？

**不是**。`100%` 是**相对计算**，基于包含块（containing block）的高度计算自己的高度。如果父元素高度是 `auto`，子元素的 `100%` 可能无效。继承是"**复制值**"，`%` 是"**算出来**"，二者本质不同。

### 3.3 `opacity` 的"伪继承"

`opacity` 属性本身**不继承**。但给父元素设 `opacity: 0.5`，子元素看起来也会变透明——这不是继承，而是因为子元素渲染在父元素这个"**半透明层**"之上。**你无法通过给子元素设 `opacity: 1` 来抵消父元素的透明度**。

`visibility` 才是真继承：父元素设 `visibility: hidden` 后，子元素可以通过 `visibility: visible` **重新显示**（因为它继承的是"**隐藏**"这个值，显式覆盖即可）；而 `opacity` 做不到。

### 3.4 继承来的值能赢过直接声明吗？

**永远不能**。继承来的值权重最低，任何直接写在元素上的声明（哪怕 `* { }` 这种零权重选择器）都会覆盖它。所以排查"样式没生效"时，先确认是不是被某个直接声明（而非继承）覆盖了。

### 3.5 `font-size` 继承的是「计算值」，不是百分比

给父元素设 `font-size: 1.2em` 时，子元素继承到的是**已经换算好的绝对字号**（父元素 `1.2em` 相对父元素的父元素算出），而不是"**再相对自己 ×1.2**"。这会导致 `em` 字号在嵌套中**逐级放大**。同理，`line-height` 的百分比也有同样的坑。
